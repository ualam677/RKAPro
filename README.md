# YGO Lab

A Yu-Gi-Oh! deck lab built on EDOPro's duel core (ocgcore): exact replay of YGO Omega lines, a line search, hand-trap and Nibiru tests, and an exact odds model for deck ratios. Currently tuned to a Galaxy-Eyes / Photon / Galaxy TCG deck.

- `sim/` headless duel engine and search tools
- `app/` web app: deck import and ratio optimiser
- `replays/` example Omega replays
- `docs/` deck knowledge, engineering notes, card texts

Setup: `./scripts/setup.sh`, then see `CLAUDE.md` for commands.
